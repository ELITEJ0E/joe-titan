# Optional Shiganshina world asset

This folder holds the converted Minecraft Shiganshina world **only when its creator has authorized public reuse**.

To enable the actual map in the game, upload the already-converted `shiganshina.jtvx` (approximately 1.03 MiB) into this folder using GitHub’s **Add file → Upload files**. The active location must be exactly:

`public/maps/shiganshina.jtvx`

The default app attempts to load `/maps/shiganshina.jtvx`. If missing, it clearly reports that condition and uses the original procedural Asterfell map instead.

The source Minecraft world ZIP itself should not be uploaded here; neither should Minecraft/Mojang texture assets without permission. See `docs/shiganshina-world-import.md` for format, credit and performance notes.
