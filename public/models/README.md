# 3D Map Assets

The live game now uses the lightweight original voxel city in `src/voxel-city.js`; it does **not** fetch a GLB at runtime.

The former realistic map has been archived at `assets/legacy/medieval-city.glb` to keep it available for future experiments without placing approximately 72 MB in every Vercel static deployment. Its old height-map file `city-collision.json` is retained here for reference only.

**Original model credit:** Daniel Vicente, [Medieval Modular City Realistic – WIP](https://sketchfab.com/3d-models/medieval-modular-city-realistic-wip-49e6306b29c74c679de8cec69473535b), CC BY 4.0 (attribution required when using the asset).
